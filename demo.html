💻 Cara Penggunaan

1. Embed (disarankan)

import { Chatbot } from '.../dist/chat-widget.js' Chatbot.init({ widgetType: "chatbot", credentials: { apiKey: "YOUR_API_KEY", username: "YOUR_USERNAME", websiteId: "YOUR_WEBSITE_ID", chatbotAgentId: "YOUR_CHATBOT_AGENT_ID", }, }); // theme + CSS dimuat otomatis (remote dari api-credential)

2. Import Component (React langsung)

import { ChatWidget } from './components/ChatWidget'; import type { ChatbotConfig } from './types';

3. Setup Configuration

const config: ChatbotConfig = { widgetType: "chatbot", credentials: { apiKey: "YOUR_API_KEY", username: "YOUR_USERNAME", websiteId: "YOUR_WEBSITE_ID", chatbotAgentId: "YOUR_CHATBOT_AGENT_ID", }, theme: { button: { backgroundColor: "#ffffff", textColor: "#0096a2", tooltip: "Ask Assistant" }, chatWindow: { header: { title: "AI Assistant" }, width: "350px", height: "600px" } } } }; // theme di sini hanya relevan untuk usage langsung; embed script menimpanya dengan theme remote

4. Render Component

function App() { return ( <div className="App"> <ChatWidget config={config} signature="" /> </div> ); } // props: config, signature (wajib), voiceName?, configErrors?

🧩 Widget Types

Embed hanya mengirim parameter minimal. Theme widget diambil remote meniru alur chatbot-ui dashboard: GET /v1/chatbot-agent/get/{username}/{agentId} (hanya dari credentials.chatbotAgentId/voiceAgentId) → api_credential_id = data_id[0] pada channel agent dengan data_type: "website" (fallback: data_id / _id agent) → GET /v1/api-credential/get/{username}/{api_credential_id} → template_data jadi theme (fallback: widget_setting agent, lalu account/get-widget) — tampilan widget selalu 1:1 dengan setting api-credential di dashboard. CSS widget (dist/chat-widget.css) disuntik otomatis oleh Chatbot.init(); tidak perlu tag <link> manual.

  • chatbot (default) → wajib credentials.chatbotAgentId + credentials.websiteId (penerima webhook). Chat memakai /v1/website/webhook + socket room {websiteId}-{phone}, 1:1 dengan chatbot-ui dashboard. Voice call jika credential men-set widget_enable_voice_ai.
  • voice-ai → credentials.voiceAgentId (fallback: widget_voice_ai_agent_id credential). Hanya panggilan, tanpa chat input.

1. chatbot (default)

Chatbot.init({ widgetType: "chatbot", credentials: { apiKey: "YOUR_API_KEY", username: "YOUR_USERNAME", websiteId: "YOUR_WEBSITE_ID", chatbotAgentId: "YOUR_CHATBOT_AGENT_ID", apiUrl: "YOUR_API_URL", // opsional }, });

2. voice-ai (calls only)

Chatbot.init({ widgetType: "voice-ai", credentials: { apiKey: "YOUR_API_KEY", username: "YOUR_USERNAME", voiceAgentId: "YOUR_VOICE_AGENT_ID", // boleh kosong jika credential punya widget_voice_ai_agent_id }, });

3. Config rusak (contoh error card)

Chatbot.init({ widgetType: "chatbot", credentials: { apiKey: "YOUR_API_KEY", username: "YOUR_USERNAME", // chatbotAgentId sengaja dikosongkan }, }); // Popup widget menampilkan kartu merah "Widget configuration error" // dan console.error berisi field yang kurang.

🔄 Perbedaan dengan Vanilla JS

  • State Management: React hooks vs DOM manipulation
  • Event Handling: React event handlers vs onclick attributes
  • Styling: Tailwind + inline styles vs template literals
  • Type Safety: Full TypeScript support
  • Component Structure: Modular React components

🎯 Keuntungan React Version

  • 🔥 Better Performance: Virtual DOM optimization
  • 🧩 Reusable Components: Modular architecture
  • 🔒 Type Safety: Full TypeScript integration
  • 🎨 Modern Styling: Tailwind CSS integration
  • ⚡ Hot Reload: Fast development experience
  • 📱 Responsive: Mobile-first design

🔖 Styling Unik dengan Prefix Tailwind CSS

Catatan: Semua class Tailwind pada widget ini memakai prefix mimin- (format prefix-first, mis. mimin:flex, mimin:hover:bg-red-500) agar tidak bentrok dengan style website client.
